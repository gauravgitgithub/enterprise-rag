# Password and Authentication Standard

## Passwords
Passwords must be at least 14 characters long. Passwords are not rotated on a schedule; they are changed only when a compromise is suspected.

## Multi-factor authentication
Hardware security keys are required for all administrator accounts. Other employees may use an authenticator app. SMS codes are not an accepted second factor.

## Password managers
Use the company password manager for all work credentials. Sharing a password over chat or email is a policy violation.
